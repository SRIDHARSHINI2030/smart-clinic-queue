# Smart Clinic Queue System

A simple web-based queue management system for clinics built with Flask.

## Features

- Add patient to queue
- Automatic token generation
- View waiting queue
- Call next patient
- Reset queue
- Display board showing current patient and waiting count

## Technologies Used

- Python
- Flask
- HTML
- JavaScript
- CSS

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the application

python app.py

3. Open browser

http://127.0.0.1:5000
